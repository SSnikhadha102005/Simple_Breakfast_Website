# Simple Breakfast

A simple static website designed to help busy students discover quick, healthy, and easy breakfast ideas.

## About the Project

Simple Breakfast provides breakfast inspiration for students who need nutritious meals that fit into a busy schedule. The website highlights:

- Quick morning recipes
- Healthy breakfast choices
- Easy-to-make meals
- Featured breakfast recommendations

The goal is to encourage healthier eating habits by providing simple meal ideas that require minimal preparation time.

## Features

- Responsive homepage layout
- Navigation menu
- Featured Breakfast of the Week section
- Recipe-focused content
- Clean and simple design
- Student-friendly meal suggestions

## Technologies Used

- HTML5
- CSS3
- GitHub Pages
